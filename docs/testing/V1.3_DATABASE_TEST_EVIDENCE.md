- PostgreSQL RLS cross-tenant read and write rejection; and
- append-only document version creation against PostgreSQL with in-memory binary storage.

They are marked `integration` because the build environment did not have the
project's Docker services running. They must be executed on the user's Windows
development machine after `Initialize-Database.ps1`.
