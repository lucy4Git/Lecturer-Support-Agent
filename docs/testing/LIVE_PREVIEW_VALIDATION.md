# Live Preview Validation

Every UI/UX change must be tested in a running application by all materially affected roles at desktop, tablet and mobile breakpoints. Cover loading, empty, success, validation error, permission denial, partial failure, retry, no verified sources, expired access, interrupted upload, duplicate version and export failure.

Checkpoint evidence lists role/account, route, viewport, action, result, screenshot/equivalent evidence, issue found, fix and retest.
