## Review-workflow validation

Infrastructure-independent validation confirms that:

- review cycles pin an exact generated-output version;
- review packs carry deterministic manifest hashes;
- assigned reviewers must use their authorised reviewer role;
- external reviewers and moderators require a matching temporary access grant;
- task acceptance, start, finding creation and immutable submission follow a controlled state machine;
- reviewer recommendations remain separate from formal academic decisions;
- changes-required and rejected decisions do not silently release an output;
- lecturer or coordinator responses preserve finding history;
- resubmission creates a new correction round, pack and reviewer task rather than mutating prior evidence;
- Heads of Department and authorised coordinators receive scoped review oversight;
- Institution Administrators retain tenant administration without automatic academic decision authority.
