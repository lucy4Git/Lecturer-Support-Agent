## v1.8 security evidence

The source and tests confirm the following intended controls:

- an internal or external reviewer must be the exact assigned user for the task;
- an external reviewer or moderator must also have an active matching access grant;
- the grant must permit the requested action and match at least one exact resource boundary;
- the sealed pack pins the generated-output version under review;
- reviewer recommendations do not directly approve or release an output;
- the Institution Administrator is not granted academic review-decision authority by default;
- findings, responses, submissions, decisions and correction rounds preserve historical evidence.

## Evidence boundary

PostgreSQL migration execution, row-level-security behaviour, live invitation and external-grant expiry, object-storage evidence, real browser interactions, live responsive testing and complete end-to-end moderation were not available as assured runtime dependencies in this environment. Those checks remain owner-machine work and are not represented as complete.
