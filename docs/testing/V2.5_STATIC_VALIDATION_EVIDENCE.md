# v2.5 Static Validation Evidence

The release validator checks:

- required v2.5 files, models, migration, routes and UI assets;
- application and package version 2.5.0;
- 124 registered SQLAlchemy tables;
- connected handlers for every allowlisted durable job, including backup and restore drill;
- account-security, SSO, integration, privacy, evaluation and data-governance routes;
- role independence;
- OER/metadata catalogue schema validity;
- PWA and legal/commercial assets;
- syntactic validity of Python, TypeScript/TSX, JSON schemas and PlantUML sources;
- absence of committed `.env` and high-confidence secrets.

Unit tests cover RFC 6238 vectors, recovery-code properties, OIDC PKCE construction, OpenAlex retrieval provenance, OneRoster staging, claim-citation coverage, exact object-version deletion and tenant-scoped backup paths.
