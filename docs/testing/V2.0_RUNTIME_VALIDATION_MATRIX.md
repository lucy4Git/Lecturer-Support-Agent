# v2.0 Runtime Validation Matrix

| Gate | Required evidence | Failure consequence |
|---|---|---|
| Environment safety | `.env` ignored; secret scan passed | Stop runtime validation |
| PostgreSQL | Query succeeds; Alembic at head | Database features unverified |
| Tenant isolation | Cross-tenant reads/writes denied | Critical security failure |
| Redis | PING succeeds | Jobs/cache/session support unverified |
| MinIO | Bucket exists and versioning enabled | Immutable file history unverified |
| Qdrant | Required collection reachable | Institutional retrieval unverified |
| Ollama | Required models installed; synthetic generation succeeds | Local/private routing unverified |
| Cloud providers | Optional synthetic request per configured provider | Provider remains configured-but-unverified |
| API | Health and readiness return successfully | End-to-end backend blocked |
| Web build | Typecheck and production build pass | UI not release-candidate ready |
| Live preview | Five roles visible at three breakpoints | Commercial UX acceptance blocked |
| Role separation | HOD cannot see Invite User; admin cannot see Assign Lecturer | Critical authorisation defect |
| Source integrity | Unsupported citations remain removed | Hallucination control failure |
| Versioning | Upload/output revisions retain history | Data integrity failure |
| Moderation | Exact task/pack/grant boundaries enforced | External-access security failure |
| Department operations | Scoped plans/readiness/workload/handover operate | Day-to-day workflow incomplete |
| Recovery | Failed stage can be rerun without destructive reset | Operational readiness blocked |

A stage is not considered passed merely because its source code exists. Evidence must come from the owner-machine run.
