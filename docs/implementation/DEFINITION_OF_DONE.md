# Definition of Done

A work item is done only when requirement/acceptance links, code, contracts and migrations are complete; authorization/tenant scope are enforced server-side; appropriate tests pass; security/accessibility/error/recovery states are covered; UI is live-preview tested by affected roles and viewports with evidence; sources and compliance language are verified; uploads are non-destructive; documentation/UML/traceability/changelog are updated; observability and rollback exist; and limitations are explicit and accepted.
