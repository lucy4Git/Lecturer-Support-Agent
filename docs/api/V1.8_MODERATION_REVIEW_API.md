# v1.8 Moderation and External Review API

Base path: `/api/v1/reviews`

## Review-cycle management

### `POST /cycles`
Creates a review cycle for an output already in `under_review` state. The request includes the review type, exact assignees, due date, review criteria and optional supporting document/export identifiers. The service seals an immutable review pack and creates one task per assignee.

### `GET /cycles/{cycle_id}`
Returns the cycle, all historical and current-round tasks, current pack items and open/blocking finding counts. Visibility is limited to the output owner, assigned reviewers or users with scoped review-read authority.

### `POST /cycles/{cycle_id}/decision`
Records an authorised academic decision after all current-round tasks have been submitted. Reviewer submissions are linked to the decision record. The decision updates the output workflow but remains separate from reviewer recommendations.

### `POST /cycles/{cycle_id}/resubmit`
Resubmits the current corrected output version. A new sealed pack and new task round are created; prior packs, tasks, findings, submissions and decisions remain immutable.

## Assigned reviewer work

### `GET /tasks`
Lists only the current user's assigned review tasks. Optional query: `status`.

### `POST /tasks/{task_id}/accept`
Accepts an assigned or returned task.

### `POST /tasks/{task_id}/start`
Starts an accepted task and moves the cycle into review where appropriate.

### `POST /tasks/{task_id}/findings`
Creates an evidence-based finding while the task is in progress.

### `PATCH /findings/{finding_id}`
Allows the finding's assigned reviewer to amend it before submission. Submitted findings are immutable.

### `POST /findings/{finding_id}/responses`
Allows the output owner or an authorised academic user to acknowledge, plan action, provide resolution evidence, dispute or clarify a finding.

### `POST /tasks/{task_id}/submit`
Creates an immutable submission with recommendation, summary, criterion assessments, reviewer declaration and SHA-256 evidence hash.

## Departmental oversight

### `GET /dashboard/departments/{organisational_unit_id}`
Returns scoped counts for active/overdue cycles, task states and open/blocking findings. It does not disclose review content from unrelated organisational units.

## External access additions

- `POST /api/v1/external-access/grants/{grant_id}/revoke`
- `POST /api/v1/external-access/expire-due`

Every external review request is re-authorised against grant status, time window, permitted action and exact resource scope.
