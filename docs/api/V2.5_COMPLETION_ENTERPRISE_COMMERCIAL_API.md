# v2.5 Completion, Enterprise and Commercial API

All protected endpoints enforce tenant context, active-role context and scoped permissions. Secret values are accepted only through local/production secret stores; tenant configuration stores secret references.

## Public authentication

- `POST /api/v1/auth/password-reset/request`
- `POST /api/v1/auth/password-reset/confirm`
- `POST /api/v1/auth/email-verification/confirm`
- `POST /api/v1/auth/sso/start`
- `POST /api/v1/auth/sso/callback`
- `POST /api/v1/auth/sso/exchange`

Password-reset requests return a neutral response whether or not the account exists.

## Account security

- `POST /api/v1/account/email-verification/request`
- `POST /api/v1/account/mfa/enrol`
- `POST /api/v1/account/mfa/confirm`
- `DELETE /api/v1/account/mfa/{device_id}`

MFA enrolment is incomplete until the user proves possession of the generated TOTP secret.

## Enterprise integrations

- `GET /api/v1/integrations`
- `POST /api/v1/integrations`
- `POST /api/v1/integrations/{connection_id}/test`
- `POST /api/v1/integrations/{connection_id}/sync`
- `GET /api/v1/integrations/{connection_id}/sync-runs`
- `GET /api/v1/sso-connections`
- `POST /api/v1/sso-connections`

Supported connector types are Canvas, Moodle, OneRoster CSV, OneRoster REST and governed generic REST. A sync run stages records and mappings; it does not silently replace institutional master data.

## Privacy

- `GET/POST /api/v1/privacy/legal-holds`
- `GET/POST /api/v1/privacy/deletion-requests`
- `POST /api/v1/privacy/deletion-requests/{request_id}/approve`
- `POST /api/v1/privacy/deletion-requests/{request_id}/execute`

Hard deletion is controlled by deployment policy, legal holds, retention rules and second approval.

## Feedback and evaluation

- `POST /api/v1/feedback`
- `GET/POST /api/v1/evaluation/campaigns`
- `POST /api/v1/evaluation/campaigns/{campaign_id}/responses`

## Data-source governance

- `GET/POST /api/v1/data-sources`
- `POST /api/v1/data-sources/{source_id}/approve`
- `POST /api/v1/data-sources/{source_id}/acquire`

Automated acquisition is limited to approved metadata connectors. Full-content acquisition requires a reviewed rights decision and a connector designed for that source.

## Operations

Existing backup and restore-drill endpoints now dispatch connected worker handlers. Results distinguish full isolated restore completion from manifest-and-catalogue validation.
