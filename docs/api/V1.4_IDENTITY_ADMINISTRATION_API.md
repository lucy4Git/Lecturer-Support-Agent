# v1.4 Identity and Administration API

Base path: `/api/v1`

## Public authentication

| Method | Path | Purpose |
|---|---|---|
| POST | `/auth/login` | Authenticate within an institution and activate one assigned role. |
| POST | `/auth/refresh` | Rotate an opaque refresh session and issue a new access token. |
| POST | `/auth/invitations/accept` | Accept a tenant invitation and materialise membership and role scopes. |

## Authenticated session

| Method | Path | Permission |
|---|---|---|
| POST | `/auth/logout` | Authenticated session; refresh session is revoked. |

## Error behaviour

- `401`: invalid credentials, access token, or refresh token.
- `403`: active role or scope does not permit the action.
- `409`: conflicting active invitation, hierarchy move, or required role selection.
- `410`: expired invitation.
- Errors never return password hashes, raw refresh-token hashes, API keys, or another tenant's data.
