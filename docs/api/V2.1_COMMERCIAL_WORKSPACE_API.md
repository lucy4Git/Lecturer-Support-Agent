# v2.1 Commercial Workspace API

All routes require an authenticated tenant context and the active role selected at login.

| Method | Route | Purpose |
|---|---|---|
| GET | `/api/v1/workspace/navigation` | Return unified navigation, role actions, and unread badge count. |
| GET | `/api/v1/workspace/summary` | Return personal workspace counts. |
| GET | `/api/v1/workspace/search?q=...` | Search authorised conversations, outputs, files, and assigned reviews. |
| GET | `/api/v1/workspace/library` | List authorised academic knowledge and immutable current versions. |
| GET | `/api/v1/workspace/files` | List personal or shared files using the same access checks. |
| GET | `/api/v1/workspace/saved-outputs` | List output versions saved by the active user. |
| POST | `/api/v1/workspace/saved-outputs` | Save one exact generated-output version. |
| DELETE | `/api/v1/workspace/saved-outputs/{id}` | Remove the active user's saved pointer only. |
| GET | `/api/v1/workspace/notifications` | List notifications addressed to the active user. |
| PATCH | `/api/v1/workspace/notifications/{id}` | Mark one addressed notification read or unread. |
| POST | `/api/v1/workspace/notifications/read-all` | Mark the active user's current notifications read. |

## Security rules

- Search results are never generated from unfiltered tenant-wide client data.
- Conversation and output search is restricted to the current user's conversations unless a later reviewed-sharing contract is added.
- Document results pass `DocumentAccessService.require_version` before being returned.
- Review-task results are limited to the exact assignee.
- Saved output creation validates that the output version belongs to the target generated output and is authorised.
- Notification operations require both tenant and recipient-user equality.
