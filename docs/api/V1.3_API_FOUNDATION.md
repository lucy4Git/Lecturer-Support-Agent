# v1.3 API Foundation

## Implemented routes

- `GET /health`
- `GET /ready`
- `GET /api/v1/documents`
- `POST /api/v1/documents/upload`
- `POST /api/v1/bulk-uploads`
- `POST /api/v1/academic-assignments/lecturers`
- `POST /api/v1/external-access/grants`

## Service behaviour

- all protected requests require a trusted request context;
- all database transactions receive tenant-local RLS settings;
- every write creates audit and outbox evidence where implemented;
- bulk upload permission is role-and-scope based, not UI-role hard-coded;
- document content goes to object storage and metadata goes to PostgreSQL;
- assignment changes preserve prior assignment history; and
- external grants are action-limited, resource-scoped, and time-limited.

## Deliberately deferred

- production OAuth/OIDC and JWT verification;
- malware scanning and archive expansion workers;
- text extraction and embedding workers;
- conversation streaming and model execution routes;
- institution/user administration routes; and
- commercial web interface.
