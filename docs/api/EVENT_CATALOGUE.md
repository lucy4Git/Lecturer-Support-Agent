# Event Catalogue

Examples: `user.role-assigned`, `course.assigned`, `upload.batch-created`, `content.version-created`, `content.canonical-changed`, `source.verified`, `ai.execution-completed`, `review.assigned`, `review.submitted`, `external-access.expired`, `export.completed`, `audit.security-alert`. Events are versioned, tenant-scoped, idempotent and contain minimal sensitive data.
