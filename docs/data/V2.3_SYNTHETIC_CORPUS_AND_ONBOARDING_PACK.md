# v2.3 Synthetic Corpus and Institution Onboarding Pack

## Synthetic corpus

`data/fixtures/safe/synthetic_academic_corpus_v2.3.jsonl` contains 36 deterministic development records: lesson plan, assessment, and rubric examples across 12 disciplines. It is suitable for parser, indexing, search, UI, and evaluation-pipeline tests. It is not an authoritative pedagogical dataset and must never be presented as institutional policy or expert-approved content.

Regenerate it with:

```bash
python scripts/data/generate_synthetic_academic_corpus.py
```

## Institution onboarding

The onboarding JSON Schema describes institution identity, terminology, arbitrary organisational hierarchy, periods, programmes, modules, users, role scopes, and governance approval. The semantic validator detects missing parents, hierarchy cycles, unknown owning units, and duplicate user emails.

```bash
python scripts/data/validate_institution_onboarding.py \
  data/manifests/example_institution_onboarding_package.json
```

The included package is synthetic and uses the reserved `.invalid` email domain. Real onboarding requires institutional authority, data-sharing approval, privacy review, and a dry-run report before database import.
