# Source Verification and Citations

The system may answer generically, but every displayed source must be genuine. “No verified source found” is preferable to a fabricated reference.

Pipeline: retrieve candidates; normalise title/author/date/publisher/URL/identifier; resolve/fetch where allowed; reject unavailable, duplicate, low-trust, irrelevant or conflicting candidates; extract supporting evidence; map claims to evidence; validate citation labels against persisted source IDs; present sources by type with limitations.

Prohibited: inventing sources or links, citing unsupported claims, claiming institutional compliance without policy evidence, or presenting suggested reading as evidence actually used when it was not retrieved and inspected.
