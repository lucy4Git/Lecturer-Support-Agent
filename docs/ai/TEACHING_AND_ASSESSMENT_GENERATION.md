# Teaching and Assessment Generation

Generation considers discipline, qualification level, outcomes, duration, delivery mode, resources, class size, accessibility, safety, language, assessment purpose and known institutional constraints.

A practical lesson may contain prerequisites, outcomes, equipment, safety, preparation, demonstration, guided/independent practice, formative checks, timing, differentiation, reflection, assessment, extension and sources.

An assessment may contain blueprint, outcome map, cognitive distribution, instructions, marks, timing, tasks/questions, rubric/memorandum, moderation notes, accessibility review and explicit human-review status.
