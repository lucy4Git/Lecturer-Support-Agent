# v2.1 Acceptance Criteria

v2.1 is accepted only when all criteria below pass.

1. All roles use the same application shell.
2. No separate artifact workspace is introduced.
3. Search returns only authorised conversations, outputs, documents, and assigned review tasks.
4. Library and Files use current immutable versions and expose version/access metadata.
5. An authorised file version can be attached to the next conversation request.
6. Saving an output retains the exact selected immutable output version.
7. Notifications are visible and mutable only by their recipient.
8. Institution Administrator and Head of Department navigation actions remain independent.
9. Desktop, tablet, and mobile views remain usable.
10. `Ctrl/Cmd + K`, focus order, labels, loading, empty, error, and reduced-motion behaviour pass.
11. Light/dark appearance does not expose or store secrets.
12. Migration `20260725_0007` applies and RLS covers `conversation.saved_outputs` and `governance.notifications`.
13. Unit, static, type-check, production-build, Playwright, tenant-isolation, and identifier-guessing tests pass.
14. Owner-machine evidence is captured before runtime acceptance.
