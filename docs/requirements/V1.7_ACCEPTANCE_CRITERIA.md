# v1.7 Acceptance Criteria

## Source/static acceptance achieved

- One conversation handles generation, editing, version history, workflow and exports.
- No separate artifact workspace is introduced.
- Five new tenant-owned tables bring the cumulative SQLAlchemy model to 69 tables.
- A module offering can be selected and stored as an immutable request snapshot.
- A manual edit or restore creates a new version and preserves prior versions.
- Institution Administrator does not receive `outputs.approve` by default.
- Assessment generation is blocked for review-only roles.
- All assessment output types require human review.
- Answer and personal-data indicators are recorded in a safety review.
- Markdown, HTML, DOCX, PDF, PPTX and XLSX renderers exist.
- Student-copy rendering removes answer sections and is lifecycle/safety gated.
- Export download re-authorises the requesting user.
- Artifact JSON Schemas are syntactically valid Draft 2020-12 schemas.
- Unit/static/cumulative validation and secret scans pass.

## Owner-machine acceptance pending

- Alembic revision runs against PostgreSQL and RLS applies to all five tables.
- Module context returns only records allowed by assignments and scope.
- MinIO stores and retrieves each export without cross-tenant access.
- Live provider output produces, edits and restores correctly.
- Role-specific workflow actions pass browser end-to-end tests.
- Student-copy release cannot expose answer keys or personal data.
- Next.js production build, responsive UX, accessibility and keyboard tests pass.
- Performance, concurrency, failure recovery and audit evidence meet agreed thresholds.

No production-readiness claim is allowed until the pending criteria are evidenced.
