# Acceptance Criteria Catalogue

## Unified response
Given an authorised request, the result renders in the same conversation as an editable/exportable structured output and never redirects to a separate artifact workspace.

## Source integrity
Every displayed citation corresponds to a persisted retrieved source record. Unresolved candidates are not shown as verified.

## Role separation
A Head of Department can assign department courses but cannot create tenant users without a separate Institution Administrator role. An Institution Administrator can manage users but does not automatically access confidential teaching/assessment content.

## Immutable upload
An exact/probable duplicate creates a new version/provenance event or non-destructive link according to an authorised choice; earlier bytes, metadata and audit remain unchanged.

## External access
Expired or revoked grants are denied immediately by the backend and the attempt is audited.
