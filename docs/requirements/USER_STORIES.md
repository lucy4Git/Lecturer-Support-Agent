# User Stories

- **US-001:** As a lecturer, generate a two-hour IoT sensor practical with outcomes, equipment, activities, timing, assessment and real sources in one conversation.
- **US-002:** As a lecturer, bulk-upload a module folder while preserving every previous version.
- **US-003:** As a coordinator, compare outcome and assessment coverage across modules.
- **US-004:** As a Head of Department, assign courses and review readiness without leaving the system.
- **US-005:** As an Institution Administrator, onboard users/materials while keeping academic authority separate.
- **US-006:** As a moderator, access only my assigned assessment and submit traceable findings.
- **US-007:** As an external reviewer, have access expire automatically after the task.
- **US-008:** As any user, see genuine sources clearly distinguished from generated content.
