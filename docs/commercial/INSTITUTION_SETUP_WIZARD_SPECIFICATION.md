# Institution Setup Wizard Specification

The wizard will guide an Institution Administrator through identity/branding, HEI terminology, organisational hierarchy, academic periods, programmes/modules, user imports, roles, policies/templates, provider policy, retention, SSO, integrations and acceptance checks. Each step supports save-and-resume, validation, import preview, rollback and an audit record. Secrets are entered through the deployment secret mechanism, not persisted in ordinary settings.
