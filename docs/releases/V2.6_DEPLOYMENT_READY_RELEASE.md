# v2.6.0 deployment-ready release

v2.6.0 closes the source-level deployment gap for the approved Vercel, Render, Neon, S3, Qdrant and SMTP topology.

Added:

- Render staging and production Blueprints with shared generated-secret and hosted-configuration environment groups;
- Vercel monorepo configuration;
- Neon runtime-role bootstrap and pre-deploy migration gate;
- Google Gemini and OpenAI cloud embedding adapters;
- provider-enforced object-versioning compatibility mode;
- controlled institutional access requests;
- production refusal of demonstration seeding;
- approved-source preflight plus PostgreSQL/object-storage/Qdrant migration tools;
- logical local-to-deployed parity manifests and verifier;
- GitHub CI, CodeQL and safe release gate;
- deployment, parity and security runbooks.

The source package contains no real environment file or credential. Actual deployment still requires the user to create vendor accounts/resources and enter secret values into their protected dashboards.

## Release boundary

The archive is ready to push to a private GitHub repository. Deployment itself still requires protected vendor accounts/resources and secret entry. Staging must import the approved local dataset before enabling the eight-role seed once; production never enables demonstration seeding.
