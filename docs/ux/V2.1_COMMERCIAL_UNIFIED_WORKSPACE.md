# v2.1 Commercial Unified Workspace UX

## One work area

The user never enters a separate lesson-plan, assessment, moderation, file, or administration application. The left navigation changes the current view inside the same shell, while generated teaching materials continue to appear and remain editable inside the conversation.

## Navigation

- **New conversation** — starts any authorised lecturer-support task.
- **Search** — global authorised search, available with `Ctrl/Cmd + K`.
- **Library** — permitted institutional and shared academic materials.
- **Files** — personal uploads and authorised shared files.
- **Saved outputs** — exact immutable versions deliberately saved by the user.
- **Notifications** — tasks, deadlines, review changes, readiness risks, and access changes addressed to the user.

## Commercial interaction requirements

- Responsive sidebar and mobile drawer.
- Clear role and teaching context.
- Search filters and informative result types.
- File status, version, visibility, access label, and AI-indexing state.
- Attach-to-conversation action without changing applications.
- Loading skeletons, empty states, errors, and disabled states.
- Light and dark appearance stored locally without placing secrets in browser storage.
- Notification count in navigation and read/unread controls.
- Role actions remain contextual and independent of the navigation views.

## Accessibility

Keyboard focus, semantic headings, labelled search fields, button-based cards, reduced-motion support, responsive target sizes, and visible status text are required. Owner-machine live preview must verify desktop, tablet, mobile, keyboard, and screen-reader landmarks.
