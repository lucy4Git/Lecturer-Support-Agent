# v1.5 Commercial Unified AI Work Area

## Experience model

The user remains in one work area for conversation, teaching-content generation, assessments, moderation assistance, departmental requests, and role-aware actions. Generated outputs appear inline; no lesson-plan, rubric, test, report, or artifact workspace is opened.

## Implemented states

- Empty conversation with capability guidance.
- Recent-conversation navigation.
- New-conversation action.
- User and assistant message presentation.
- Generating indicator.
- Inline output type badge.
- Provider/model execution disclosure for transparency.
- Human-review notice for high-stakes outputs.
- Citation-integrity warning.
- Expandable source cards with retrieved/cited status.
- Contextual role-action drawer.
- Responsive mobile navigation.
- Error notice with retained composer text after failed send.

## Commercial-readiness direction

The UI intentionally follows the interaction simplicity of leading conversational AI systems while retaining institutional role controls. v1.5 is a functional foundation, not a final design acceptance. Live preview, keyboard navigation, screen-reader review, reduced-motion behaviour, colour contrast, loading recovery, and browser/device testing remain required before approval.

## Deferred UX

- Streaming token rendering.
- Attachment chips and upload progress.
- Rich table rendering and syntax-aware Markdown.
- Output selection, partial regeneration, and version comparison.
- Voice input.
- Saved-output export actions.
- Production drag-and-drop bulk upload.
