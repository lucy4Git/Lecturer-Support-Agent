# Information Architecture

Primary navigation stays compact: New conversation, Search, Recent conversations, Library/available content, Assigned work/reviews, Saved outputs/versions, contextual department/administration actions, and profile/accessibility/settings. Bulk upload is an action inside relevant contexts, not a separate permanent workspace.

## v2.1 commercial unified workspace

The principal shell now exposes **New conversation, Search, Recent conversations, Library, Files, Saved outputs, and Notifications** as views of one role-aware application. These views support the same conversation workflow; they are not independent AI applications or separate artifact workspaces. Role-specific operational actions remain contextual and permissions are enforced by the backend.
