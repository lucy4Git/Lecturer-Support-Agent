# v1.4 Unified Role-Aware Shell

The web client does not create a separate administration product or separate artifact workspace.

## Layout

- Left navigation: new conversation, search, recent conversations, Library, Files, and Saved outputs.
- Centre: the single conversation and output area.
- Bottom: one message composer with attachment action.
- Right contextual rail: authorised role operations opened without leaving the work area.

## Context actions

### Institution Administrator

- Invite user.
- Configure institution structure.
- Access contextual bulk upload.
- Future: user list, role and position management, calendars, and templates.

### Head of Department

- Assign lecturer.
- Review department overview.
- Access contextual bulk upload.
- API support also exists for coordinator and moderator assignment.

### Other teaching and review roles

- Retain the same work area.
- Receive only actions allowed by the active role and assigned scope.
- Bulk upload remains contextual where permission exists.

The interface may hide unavailable actions for clarity, but the backend independently rejects unauthorised requests. A user-controlled role cookie affects presentation only and never grants authority.
