# Responsive Multi-Platform UX

Support desktop/laptop, tablet portrait/landscape, mobile web/PWA, Windows, macOS, Linux, Android and iOS browsers. Navigation collapses without losing task status; the composer remains usable above virtual keyboards; inline artifacts reflow; tables offer accessible alternate/horizontal views; upload uses supported file/folder/camera pickers and resumable progress; drafts recover where policy permits.

Target WCAG 2.2 AA, including keyboard, screen readers, streaming announcements, focus management, contrast, zoom/reflow, reduced motion, captions/transcripts and understandable errors.
