# Unified AI Work Area

The application opens into one modern conversational workspace. Users type, speak where supported, attach files/folders, reference modules or assignments and request any authorised lecturer-support task.

Responses may include a direct explanation, editable inline artifact, tables, source markers/cards, assumptions, warnings and contextual actions such as revise, adapt level, map outcomes, check sources, compare versions, submit for moderation, assign, export or bulk upload.

## No separate artifact workspace

Lesson plans, rubrics, tests, reports and moderation outputs remain in the same conversation. A wide-screen expanded or split presentation is allowed only when it preserves the same conversation and navigation context.

## Role-aware actions

- Lecturer: author, upload, version and export assigned module content.
- Coordinator: alignment, comparison and programme/module bulk upload.
- Head of Department: course assignment, departmental review, moderator assignment and department bulk upload.
- Institution Administrator: tenant users, roles, structures, institutional content onboarding and audit.
- Moderator/reviewer: assigned review, findings, permitted uploads and submit/return.

## Essential states

Loading, streaming, empty, no-source, partial-source, permission denied, expired access, offline draft, interrupted upload, duplicate detected, processing, partial success, item error, review returned and export failure.

## v2.1 navigation and personal work surfaces

The unified work area now allows a user to search authorised resources, attach a Library or Files version to the next prompt, save an exact generated-output version, and act on notifications without leaving the application shell. Ordinary users never select providers, models, agents, or orchestration workflows.
