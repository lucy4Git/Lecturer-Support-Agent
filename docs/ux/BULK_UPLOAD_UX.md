# Bulk Upload UX

The bulk-upload button appears in the current context for authorised users. Support drag/drop, folder/ZIP selection, manifest import, resumable progress, metadata preview, duplicate clusters, item errors, confirmation and downloadable batch reports.

Use wording such as “create new version,” “link to existing” or “create new item”—never “replace existing file.” Show uploader, role, time, scope and prior-version relationship before confirmation.
