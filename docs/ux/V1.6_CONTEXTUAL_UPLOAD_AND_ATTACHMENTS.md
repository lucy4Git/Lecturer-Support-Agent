# v1.6 contextual upload and attachments

Bulk upload is available through the same role-aware action rail and the composer attachment button. It is not an administrator-only screen and does not create a separate artifact workspace.

The interface supports multiple files and safe ZIP archives, shows selected files, captures content type, scope, visibility, and change reason, and returns stored version identifiers. Successfully stored versions are attached as chips to the user's next message. The user may remove a chip before sending.

Institutional source cards are visually distinguished from external sources and retain document-version and locator metadata without exposing restricted content to unauthorised users.
