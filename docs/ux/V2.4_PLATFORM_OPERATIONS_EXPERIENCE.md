# v2.4 Platform Operations Experience

The Institution Administrator receives a **Platform operations** view inside the same commercial Lecturer Support Agent shell. It is not a separate application.

The view provides:

- Queue and dead-letter summary
- Recent durable jobs
- Governed interval schedules
- Retention preview and reversible execution controls
- Retention-run evidence
- In-app notification-delivery evidence
- Clear pending, completed, blocked and failed states

The Head of Department does not receive this view. The Head of Department continues to use the separate teaching-operations functions defined for departmental academic work.
