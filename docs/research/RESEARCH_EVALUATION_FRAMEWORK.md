# Research Evaluation Framework

Evaluate functional task success for every role; pedagogical quality across disciplines/levels; assessment alignment/validity/clarity; source correctness and fabricated-reference rate; role compliance, tenant isolation, external access, audit and version integrity; usability, accessibility, trust, workload reduction and time saved; latency, throughput, batch processing, scalability, availability and cost.

Use benchmark tasks, expert rubrics, automated regression, role-based usability studies, security tests and ethically approved pilot telemetry.
