# Glossary

- **Artifact:** A structured output rendered and edited inline in the conversation.
- **Canonical version:** The currently designated authoritative version; earlier versions remain immutable.
- **External reviewer:** A temporary scoped user limited to assigned review tasks.
- **HEI:** Higher Education Institution.
- **Organisational scope:** Tenant/unit subtree within which a role or content item applies.
- **Provenance:** Who created/uploaded content, when, why, from where and through which batch/workflow.
- **Source verification:** Validation of genuine source identity, metadata, accessibility and claim support.
- **Unified work area:** The single interface where authorised users perform all lecturer-support work.
- **Version:** An immutable snapshot linked to a stable content identity and prior revision.
