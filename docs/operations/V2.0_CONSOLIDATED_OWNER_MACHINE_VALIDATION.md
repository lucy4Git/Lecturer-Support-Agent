# v2.0 Consolidated Owner-Machine Validation

## Before running

1. Extract the v2.0 package outside OneDrive, preferably to `C:\Projects\Lecturer-Support-Agent`.
2. Start Docker Desktop manually. Project scripts will not start it.
3. Confirm Ollama is running and contains `qwen3:8b` and `nomic-embed-text-v2-moe`.
4. Create `.env` from `.env.example` and run `scripts/security/Initialize-LocalSecrets.ps1`.
5. Add only the provider keys you intend to test. `.env` must remain ignored.
6. Open PowerShell at the project root.

## Complete command

```powershell
Set-ExecutionPolicy -Scope Process Bypass

.\scriptsalidation\Invoke-ConsolidatedOwnerValidation.ps1 `
  -Mode full `
  -InstallDependencies `
  -StartInfrastructure `
  -RunLivePreview
```

Add `-IncludeCloudProviderProbes` only when you deliberately want a minimal synthetic request sent to each configured cloud provider. No institutional or user content is used by those probes.

## What the command does

- Captures machine metadata without secrets.
- Verifies `.env` is ignored and no high-confidence credentials are committed.
- Runs every cumulative static validator and unit test.
- Checks required tools and Ollama models.
- Starts PostgreSQL, Redis, MinIO and Qdrant only when `-StartInfrastructure` is supplied and Docker is already running.
- Applies Alembic migrations, initialises Qdrant and seeds two synthetic institutions.
- Runs integration and tenant-isolation tests.
- Type-checks and builds the Next.js application.
- Starts the API and production web server for live preview.
- Probes live dependencies and local model inference.
- Runs role-aware Playwright checks at desktop, tablet and mobile breakpoints.
- Writes redacted evidence and a final report to `runtime/validation/<timestamp>/`.

## Passing result

The final report must show `overall_status: passed` and `runtime_claim: validated_on_owner_machine`. Any failed stage keeps the project in validation-pending status.

## Evidence to retain

Retain the Markdown and JSON summary, stage logs, runtime probe JSON, screenshots, Playwright traces for failures, migration output and test output. Do not upload the whole runtime directory until it has been reviewed for confidential data.

## After a pass

Create a Git commit containing code corrections and documentation updates, but not the ignored runtime evidence. Provide Claude with the redacted validation report and screenshots separately for audit.
