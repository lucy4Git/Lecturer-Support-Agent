# v1.9 Owner-Machine Validation

Run this only during the consolidated owner-machine validation checkpoint.

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\database\Start-DatabaseStack.ps1
.\scripts\database\Run-Migrations.ps1
python -m pytest tests/unit -q
.\scripts\validation\Validate-V1.9.ps1 -RunTests
```

Validate in the browser with seeded roles:

1. Lecturer creates a teaching plan, adds sessions, records a delivered session, updates readiness evidence, views own workload, and submits a handover.
2. Head of Department reviews the departmental dashboard, allocates workload, manages calendar events, requests handover changes, and confirms module readiness.
3. Institution Administrator can manage institution calendar configuration but cannot perform Head of Department workload or handover duties unless separately assigned that role.
4. A lecturer from another institution cannot see or modify the first tenant's operational records.
5. Invalid session, readiness, and handover transitions return safe errors and retain prior history.

Capture migration logs, API responses, database RLS evidence, and live-preview screenshots as validation evidence.
