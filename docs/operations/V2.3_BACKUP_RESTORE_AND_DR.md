# v2.3 Backup, Restore, and Disaster-Recovery Automation

## Backup

```powershell
.\scripts\operations\Backup-Platform.ps1 -IncludeMinio -IncludeQdrant
```

The script captures PostgreSQL, optionally MinIO and Qdrant, non-secret configuration templates, SHA-256 checksums, and a manifest. Redis is not treated as an authoritative backup source.

## Verify

```powershell
.\scripts\operations\Test-BackupManifest.ps1 -BackupDirectory runtime\backups\<timestamp>
```

## Restore

Restore is intentionally destructive and requires both PowerShell confirmation semantics and `-ConfirmDestructive`.

```powershell
.\scripts\operations\Restore-Platform.ps1 `
  -BackupDirectory runtime\backups\<timestamp> `
  -RestoreMinio -RestoreQdrant -ConfirmDestructive
```

After restoration, run migrations, readiness probes, tenant-isolation tests, authentication tests, version-integrity tests, and representative role workflows before reopening access.

## Evidence still required

A successful backup is not proof of recoverability. Staging must perform scheduled isolated restore drills and record RPO, RTO, checksums, tenant boundaries, object versions, audit records, and corrective actions.
