# v1.3 Local Database Setup on Windows

## Prerequisites

- Python 3.11 or later
- Docker engine available and started manually
- PowerShell
- the project extracted outside a synchronised OneDrive folder where practical

## Safe environment setup

```powershell
Copy-Item .env.example .env
code .env
git check-ignore -v .env
```

Replace every `change-*` value. Do not place cloud API keys in `.env.example`.

## Start local data services

The script checks Docker but never launches Docker Desktop:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\database\Start-DatabaseStack.ps1
```

## Install Python dependencies and initialise

```powershell
.\scripts\database\Initialize-Database.ps1 `
  -InstallDependencies `
  -SeedDemonstrationData
```

This runs the Alembic migration, creates the Qdrant collection, enables MinIO
bucket versioning, and loads synthetic demonstration tenants.

## Run verification

```powershell
python -m pytest tests/unit -v
.\scripts\database\Test-TenantIsolation.ps1
```

## Start the API

```powershell
python -m uvicorn services.api.app.main:app --reload --port 8000
```

Open `/docs` for the local OpenAPI interface. Protected development endpoints
require the synthetic tenant, user, and role headers documented in
`services/api/README.md`.

## Stop without deleting data

```powershell
.\scripts\database\Stop-DatabaseStack.ps1
```

## Destructive reset

```powershell
.\scripts\database\Reset-DevelopmentDatabase.ps1 -ConfirmReset
```

The reset removes local named volumes and must never be run against required data.
