# Integrations and Data Steward Quick Start

1. Create the connection using a secret reference, not a token value.
2. Test connectivity with a non-production account.
3. Run a bounded staging sync.
4. Review record counts, mappings, duplicates and errors.
5. Approve field mappings before canonical adoption.
6. Preserve source identifiers and sync evidence.
7. Revoke the integration secret when access is no longer required.
