# Configuration

Version-controlled, secret-free configuration examples live here. Real credentials and tenant-specific production settings must be supplied through an approved secret manager or deployment environment.

- `ai/providers.example.json` — provider adapters and capability hints.
- `ai/model-registry.example.json` — stable aliases and candidate local models.
- `ai/ollama-model-profiles.json` — local download profiles used by PowerShell.
