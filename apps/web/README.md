# Responsive Web Client — v2.1

The web client provides the commercial unified Lecturer Support Agent experience.

- One ChatGPT-style work area; no separate teaching-artifact or administrative application.
- New conversation, authorised Search, Recent conversations, Library, Files, Saved outputs, and Notifications.
- Contextual Institution Administrator, Head of Department, Lecturer, Coordinator, Moderator, and External Reviewer actions.
- Library or Files versions can be attached to the next conversation prompt.
- Generated outputs can be saved by exact immutable version.
- Responsive desktop, tablet, and mobile navigation, keyboard Search (`Ctrl/Cmd+K`), loading, empty, success, warning, and error states.
- Light and dark appearance support.
- Secure backend-for-frontend routing with HTTP-only access and refresh cookies.
- Provider credentials never reach browser JavaScript.

Owner-machine dependency installation, production build, live preview, accessibility, responsive-device, and end-to-end validation remain pending.
